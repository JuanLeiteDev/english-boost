How to use the app, what is behind it, and how to run it on another computer (Linux, macOS or Windows).

01Start the app

docker compose up -d     # start (it also starts with Docker)
docker compose down      # stop
./estudar.sh
estudar.bat

Then open http://127.0.0.1:8765. Use only one way at a time: they share port 8765.

02One study day

  1. Open Today. You see the plan for the day: 4 blocks and a timer.
  2. Start the timer (the round button).
  3. Vocabulary (8 min): review your AnkiWeb cards and add today's new words.
  4. Grammar (22 min): press Open. Write your answers, press Check, then Save. Wrong answers? Press Explain my mistakes.
  5. Listening (15 min): press Open. Predict, listen, check, read the transcript, then shadow for 3 minutes.
  6. Output (15 min): press Practise. Speak (mic) or write. The tutor gives short feedback.
  7. Finish session and check the form (see below).
  8. Progress → Save to GitHub to keep your work safe.

03Finish a session: what to write

Press Finish session at the end of Today. Most fields fill in by themselves. Check them and press Save session.

05Microphone

Press the mic in the chat, speak, then press it again to stop. Your words appear in the message box. Check them and send.

  • Docker app (best): the recording is transcribed on your computer with Whisper. It works in every browser (Chrome, Edge, Firefox), it is private and it works offline. The first start downloads the model once (about 150 MB).
  • Without Docker: the app uses Chrome or Edge dictation (it needs Google's servers). If it fails, use the Docker app.
  • The browser asks for permission the first time: press Allow.

07How it works

There is no database and no cloud: everything is text files in the project, saved with Git. The app connects the browser, these files and the agents.

  • Chat: the server starts the agent's command-line tool in the project folder and streams its answer to the browser. Each agent keeps its own conversation (--resume).
  • Opening material: when an answer contains [[open:P1-02]], [[open:today]] or [[open:doc:…]], the app opens it in the centre.
  • Exercises: answer keys are read only when you press Check. Contractions and small differences count as right; it is right fixes a wrong mark.
  • Agents: both read AGENTS.md and the skills in .agents/skills/. A rule there makes them use only simple English.
  • Tests: python3 -m unittest discover -s tests -t .. GitHub Actions runs them on Linux, Windows and macOS for every push.

09Docker

A container is a small, separate Linux that runs inside your system. On Windows and macOS, Docker Desktop runs it in a small virtual machine. So the app works the same everywhere.

10Security

  • The app listens only on 127.0.0.1; other devices on your network cannot open it.
  • Every action needs a secret token that changes on each start, and the Host header must be local.
  • Answer keys and files outside the project cannot be opened from the page.
  • Not saved in Git: chat history (app/state/), .env, and the Cambridge papers (copyright).
  • The repository is public. Your texts and progress are visible. To make it private: gh repo edit JuanLeiteDev/english-boost --visibility private --accept-visibility-change-consequences

11Install on another computer

  1. Install Docker. Windows/macOS: Docker Desktop. Linux: Docker Engine, then sudo usermod -aG docker $USER and log in again.
  2. Get the project and build (3–5 min the first time): 
    git clone https://github.com/JuanLeiteDev/english-boost.git
cd english-boost
docker compose build
  3. Log in once (Claude, Codex, GitHub): 
    docker compose run --rm app login
  4. Start and open http://127.0.0.1:8765: 
    docker compose up -d
git clone https://github.com/JuanLeiteDev/english-boost.git && cd english-boost
bash scripts/setup.sh      # skills link, materials, finds the agents
./estudar.sh

You need Python 3.9+, Git, and Claude Code (VS Code extension) and/or Codex (app or npm i -g @openai/codex).

git clone https://github.com/JuanLeiteDev/english-boost.git; cd english-boost
powershell -ExecutionPolicy Bypass -File scripts\setup-windows.ps1
.\estudar.bat

You need Python (winget install Python.Python.3.12), Git, and Claude Code and/or Codex. Docker is easier and the same everywhere.

12Problems

The mic does nothing or shows an error

Allow the microphone in the browser (lock icon in the address bar). Without Docker, use Chrome or Edge. In Docker, the first transcription can take a minute while the model loads.

"Claude/Codex not found"

Docker: docker compose run --rm app status, then login if needed. Without Docker: Settings, then enter the path of the program.

The agent says the login expired

Docker: docker compose run --rm app login. Without Docker: open Claude Code or the Codex app and log in again.

Port 8765 is busy

The normal app and Docker are both running. Stop one, or use HOST_PORT=8766 in .env.

"Permission denied … docker.sock" (Linux)

sudo usermod -aG docker $USER, then log out and in again.

"Today" shows the wrong day

Set TZ=Europe/Brussels (or Europe/Lisbon) in .env and run docker compose up -d.
